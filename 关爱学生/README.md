# 关爱学生

中小学关爱学生业务第一版多端原型及第二版控辍保学联动演示。更新日期：2026-10-08。

## 内容

- `原型/`：七端最新演示页面及配套本地脚本、样式与 DOM 测试。请下载完整目录，保留相对路径；GitHub 文件页用于查看源码，并非在线运行页。
- `需求文档/`：第一版老师端、学校端、四级监管端及家长端需求文档，以及第二版控辍保学联动方案。

打开 `原型/老师端关爱管理-V2.9-20260929.html` 可查看老师端关爱个案与控辍预警的联动。第一版关爱个案数据与第二版预警入口共用，预警详情分别展示劝返和关爱记录。演示用本学年预警及劝返日期为 2026 年 9 月。

## 状态说明

此目录为前端原型，不含生产后端或跨端持久化。第二版以一个原始预警对应一个个案；首次关爱先填类型、锁定来源控辍保学、关联控辍保学与原因，下一步复用第一版内容表单；首条保存建案，后续继续关爱直接填写内容。正式实现必须使用预警 ID、学生 ID、学校 ID、学年及个案 ID，不得按姓名匹配。

已执行七端启动、语法、引用及主要流程 DOM 回归；真实浏览器视觉、触摸与上传仍需验收。测试需 jsdom 22.1.0，使用 Node 运行两个 `.test.cjs` 文件。具体清理方式及边界见需求文档中的代码核对与清理记录。历史核对过程不作为当前实现状态。
