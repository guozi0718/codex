# 老师端小程序·班级评价产品需求文档

> 产品版本：V1.0.0（第一版）
> 文档版本：V1.0.0_260915
> 文档日期：2026-09-15
> 适用范围：学校侧老师端小程序「班级评价」模块
> 文档原则：本文仅描述最终原型已确认的页面、字段、交互、数据口径与异常处理；同一页面的字段及其逻辑集中于该页面章节，不描述中间方案或已删除能力。

## 需求背景

学校需要面向校长、班主任和任课老师提供统一的班级评价入口：老师在授权范围内完成当日班级加分、扣分和学生关联，学校按统一计分口径查看班级排行及评价记录；同时需要保留提交时的配置、人员、班级、学生和分值快照，避免后续组织、指标或教师配置变化影响历史统计与审计。

## 文档说明

### 名词解释

| 术语 / 缩略词 | 说明 |
|---|---|
| 学年 | 学校端校历定义的当前学年；老师端仅查看当前学年数据，不提供往学年切换。 |
| 学期 | 学校端校历定义的当前学期；学期起止、学年起止不在小程序端硬编码。 |
| 业务日期 | 学校端返回的当前学校日期；用于今日评价、未来日期禁用、跨日提交和分组状态判断，不使用客户端自行推断结果。 |
| 可评价时间 | 学校端排班表与当前学年日期范围的交集；交集外日期不可发起评价。 |
| 初始分 | 学校端系统统一配置的班级评价初始总分；本版本原型展示为 100 分。 |
| 净得分 | 同一时间范围、同一一级指标维度内的总加分减总扣分；总扣分按绝对值参与计算。 |
| 评价记录 | 一条“班级 × 检查项 × 加/扣分方向”的成功提交快照；一次完成评价包含多个班级或检查项时拆分为多条记录。 |
| 在评内容 | 今日评价页内已确认、尚未完成评价提交的检查项草稿；不属于正式评价记录。 |
| 正评价弹窗 | 点击检查项或编辑在评项时打开的评价编辑弹窗，包含评分、图文评价、关联学生三个 tab。 |
| 评价权限 | 老师在某日期、某班级范围内发起评价的权限；来源为学校端点评教师配置与值周老师分组有效范围的并集，正式结果以学校端返回为准。 |
| 历史快照 | 成功提交时固化的评价时间、班级、学生、指标、检查项、方向、实际分值、评价人员及附件等数据；后续配置变化不回写该快照。 |

## 需求范围

| 功能点 | 说明 | 负责人 |
|---|---|---|
| 排行 | 在当前学年内，按本周、本月、本学期、本学年查看班级全部维度总分或单一级指标净得分排名。 | 老师端 |
| 评价 | 在学校端实时授权的班级范围内，按指定业务日期查看班级加扣分并进入今日评价；历史日期只用于查看，不支持补录。 | 老师端、学校端 |
| 今日评价 | 通过扫码、单班或多班进入，对学校端实时检查指标库中的检查项进行评价、关联学生并批量提交。 | 老师端、学校端 |
| 评价记录 | 查询当前学年已成功提交的检查项记录，筛选、懒加载、查看快照；本人仅可修改评价内容或删除本人记录。 | 老师端、学校端 |
| 值周老师管理 | 仅校长管理值周老师分组、成员、负责年级和执行时间；分组有效期参与评价权限结果。 | 校长、学校端 |
| 不在本版本范围 | 不支持历史日期补录；不支持修改已提交记录的评价日期、评分、检查项、评价对象或关联学生；不支持查看往学年数据；小程序端不配置学校校历、初始分、指标库或点评权限规则。 | — |

## 功能详细说明

### 班级评价

#### 统计范围

统计与排行的日期归属以**评价记录的原评价日期时间快照**为准。编辑评价内容不会改变评价日期、时间、分值或归属周期；因此不会改变该记录参与的本周、本月、本学期、本学年统计与排行。删除成功后，该记录从前端有效记录集合移除，并在所属时间范围内重新汇总排行榜、评价页加扣分和记录页统计；后端仍保留删除前快照、删除人和删除日期用于审计。

| 统计周期 | 时间范围 | 默认值 | 枚举与边界 |
|---|---|---|---|
| 本周 | 学校端校历定义的当前自然周；周归属以该周周一所属月份计算。 | 是 | 仅统计当前周已发生且提交成功、未被前端删除的记录；不显示未来日期记录。 |
| 本月 | 学校端校历定义的当前自然月。 | 否 | 仅统计当前月已发生且提交成功、未被前端删除的记录。 |
| 本学期 | 学校端校历定义的当前学期。 | 否 | 起止日期由学校端提供；不在老师端固定 2 月、8 月等边界。 |
| 本学年 | 学校端校历定义的当前学年。 | 否 | 起止日期由学校端提供；老师端查询与评价均不跨当前学年。 |
| 今日评价日期 | 当前业务日期或当前学年内历史日期。 | 今日 | 评价 tab 日历可选历史日期；未来日期及未来月份置灰不可选择；历史日期展示为“YYYY-MM-DD”，当前业务日期展示为“今日”。仅业务日期可进入今日评价，历史日期只读查看班级加扣分。 |

#### 计分规则

| 字段 / 规则 | 数据来源 | 计算与展示逻辑 | 联动、快照与异常 |
|---|---|---|---|
| 全部维度总分 | 学校端统一初始分、有效评价记录 | 同一时间维度下，`总分 = 初始分 + 各一级指标净得分`；原型默认初始分为 100 分；班级总分范围为 -99999.9 至 +99999.9 分，保留 1 位小数。 | 进行中的本周、本月、本学期、本学年使用学校端最新初始分计算当前汇总；已结束周期使用该周期形成时的初始分与记录分值快照。 |
| 一级指标净得分 | 有效评价记录的一级指标快照、加扣分方向和实际分值 | 同一时间维度下，`净得分 = 总加分 − 总扣分绝对值`；班级一级指标净得分范围为 -99999.9 至 +99999.9 分，保留 1 位小数。 | 单一级指标排行不叠加初始分；删除记录后按该记录原时间范围重新计算。 |
| 班级得分范围 | 学校端统计计算结果 | 班级在任一时间维度下展示的总分或净得分均使用 -99999.9 至 +99999.9 分的数值范围；分值边界包含 -99999.9 与 +99999.9。 | 该范围适用于排行、评价 tab 班级加扣分汇总及记录 tab 统计结果；正式服务端计算与接口返回须遵守该数值范围，前端仅按服务端有效结果展示。 |
| 检查项默认分值 | 学校端 Web【班级评价】-【检查项管理】实时配置 | 学校端保证每个可用检查项均配置 0.1–9999.9 分、最多 1 位小数的默认分值；打开正评价弹窗时该值作为评分初始值；加分、扣分方向由检查项配置决定；学校端配置顺序决定页面展示顺序。 | 本版本不存在默认分值为 0 或缺失的检查项；未提交时学校端改变检查项名称、分值、方向、启用状态或层级，当前草稿校验失败并提示“检查项已变更，请重新进入当前页面”；已提交记录只展示提交快照。 |
| 单项实际分值 | 用户在正评价弹窗确认的分值 | 仅允许正数、最多 1 位小数，范围为 0.1–9999.9 分；加分记录以正数保存并展示“+N.N”，扣分记录以负数保存并展示“-N.N”。 | 输入小于 0.1 提示“单个检查项最低为0.1分”；大于 9999.9 提示“单个检查项不允许超过9999.9分”；不允许负数、空值或超过 1 位小数。 |
| 加减按钮步长 | 当前检查项默认分值、当前实际分值 | 每次点击“+”或“−”均按**该检查项默认分值**增减一个步长，而非按 0.1 增减；例如默认分值为 0.2 分，用户手动输入 0.1 分后点击“+”，结果为 0.3 分。 | 点击“−”后的结果低于 0.1 时固定为 0.1；当前值为 0.1 时“−”按钮不可用；点击“+”后若超过 9999.9，不改变当前值并提示上限文案。 |
| 关联学生与分值 | 当前弹窗选择的学生、目标班级 | 关联学生仅为记录快照，不按人数自动计算，不改变用户确认的分值；单班、多班、关联或不关联学生均按同一检查项确认分值计入对应班级。 | 多班时每个目标班级分别生成记录；某学生仅写入其当前所属班级的记录；未关联学生的班级仍正常生成相同分值记录。 |
| 提交时分值快照 | 成功提交的检查项、用户确认分值 | 记录保存实际分值、默认分值、方向、检查项标识和配置版本；后续默认分值或上下限变更不修改已提交记录。 | 已提交记录不允许修改评分；因此编辑评价内容不会改变排行、评价页加扣分、记录页统计或原评价时间归属。 |

#### 排行 tab

##### 页面目标

在当前学年内，为有查看权限的老师提供班级横向排名；既可查看全部维度总分，也可查看某一级指标维度净得分。

##### 查询条件

| 字段 / 按钮 | 数据来源 | 展示与默认值 | 交互、校验、状态及异常 |
|---|---|---|---|
| 顶部返回 | 固定入口 | 标题固定“班级评价”。 | 点击返回学校首页；不回到上一次 tab 或子页面。 |
| 年级筛选 | 学校端当前学年年级数据 | 默认“全部年级”；展示“全部年级”和全部可查看年级。 | 点击年级卡立即选中并刷新，不展示取消、确定按钮；“全部年级”与具体年级互斥；无选择时恢复默认“全部年级”。 |
| 时间维度 | 学校端校历、当前业务日期 | 默认“本周”；可选“本周、本月、本学期、本学年”。 | 不提供“今日”“昨日”“上周”“上月”或自定义日期；切换后同步刷新排名、分值和说明弹窗的统计语义。 |
| 一级指标维度筛选 | 学校端检查指标库一级维度 | 默认“全部维度”；可选全部维度及所有一级维度，按学校端配置顺序展示。 | 横向无感滑动；选择后刷新排序、分值标题与统计说明；学校端变更顺序实时影响后续选项顺序。 |
| 总分 / 净得分说明按钮 | 固定说明文案、当前维度状态 | “全部维度”时字段名称为“总分”；选择一级维度时字段名称为“净得分”。 | 点击弹出说明：<br>全部维度：1.评分方式：按时间维度进行总分排名；2.总分计算：同一时间维度下，总分=初始分+各一级指标的净得分；3.默认初始分：100分。<br>一级维度：1.评分方式：按时间维度进行净得分排名；2.净得分计算：同一时间维度下，净得分=总加分-总扣分，总扣分取绝对值。<br>底部仅显示“关闭”按钮，使用全局确定按钮样式。 |

##### 数据区域与班级卡片

| 字段 / 区域 | 数据来源 | 展示与默认值 | 交互、校验、状态及异常 |
|---|---|---|---|
| 排名数据容器 | 当前筛选条件下的有效评价记录、初始分 | 支持容器上下无感滑动，不展示明显滚动块；无数据时展示统一空状态。 | 切换年级、时间或维度后从顶部重新渲染；仅统计当前学年、提交成功且未被前端删除的记录。 |
| 班级名称 | 当前学年年级名称、班级名称 | 全局班级字段展示为“年级名称-班级名称”，例如“一年级-1班”。 | 排行卡片仅展示，不进入今日评价。 |
| 排名 | 当前筛选后的计算结果 | 按分值从高到低排名；相同分值同名次并跳号。 | 同分时按班级创建时间排序；创建时间也相同时按班级 ID 稳定排序，保证列表顺序不抖动。 |
| 总分 / 净得分 | 当前时间范围的实时汇总 | 按当前维度显示“总分”或“净得分”，保留 1 位小数；班级得分范围为 -99999.9 至 +99999.9 分。 | 编辑评价内容不触发重算；删除记录后按该记录原评价时间归属同步重算对应周期及当前可见排行。 |

#### 评价 tab

##### 页面目标

展示当前老师在指定日期有权操作评价的班级及其当日加分、扣分，提供扫码、单班和多班进入今日评价的入口；历史日期仅展示，不允许新增评价。

##### 页面字段与交互

| 字段 / 按钮 | 数据来源 | 展示与默认值 | 交互、校验、状态及异常 |
|---|---|---|---|
| 顶部返回 | 固定入口 | 标题固定“班级评价”。 | 点击返回学校首页。 |
| 顶部结构 | 固定页面结构 | 不展示旧版蓝色时间区、当日实时说明或周日期条。 | 筛选区与数据区间距按原型统一；页面仅保留评价所需筛选与班级数据。 |
| 全部年级筛选 | 当前老师有评价权限的班级所属年级 | 默认“全部年级”；仅展示有可评价班级的年级。 | 点击后即时选中生效，无取消、确定；选择具体年级后仅显示该年级；恢复“全部年级”显示全部可评价年级。 |
| 全部维度筛选 | 学校端一级指标维度 | 默认“全部维度”；展示全部维度和学校端一级维度。 | 选择后按该一级维度刷新每班加分、扣分；与年级、日期条件采用“且”关系。 |
| 日期筛选 | 学校端校历、当前业务日期 | 默认“今日”；历史日期展示“YYYY-MM-DD”。 | 点击打开“选择日期”底部弹窗：中部月度日历、可切换历史月和当前月；未来日期置灰不可点，未来月份不可切换；当前业务日期选中后展示“今日”；仅当前学年内日期可选，超范围提示“评价记录时间不可超过本学年”。 |
| 扫码入口 | 固定入口、摄像头及校徽识别结果 | 与“多班评价”同一行，各占一半；展示扫码 icon 和“扫码评价”。 | 扫码成功打开扫码评价弹窗；取消扫码无提示；无摄像头权限提示“无摄像头权限，请打开摄像头”。 |
| 多班评价入口 | 当前老师有评价权限的班级 | 与扫码入口同一行，各占一半；展示多班评价 icon 和“多班评价”。 | 打开多班选择弹窗；无可评价班级时展示空状态；无权限班级不可选择，点击提示“暂无点评权限”。 |
| 年级分组 | 当前筛选后的可评价班级 | 年级标题展示年级名称和班级数；默认展开；数据区上下无感滑动。 | 点击折叠按钮切换当前年级展开/收起，不影响其他年级；不展示无权限班级。 |
| 班级名称 | 当前学年班级名称 | 在年级分组内仅展示班级名称，例如“1班”，不重复显示年级名称。 | 点击班级名称进入今日评价，并带入该班级；历史日期下班级名称只读，不进入今日评价。 |
| 班级加分 / 扣分 | 当前日期、维度、班级的有效评价记录 | 每个班级卡分别展示加分和扣分，均保留 1 位小数，使用全局加分/扣分颜色。 | 当前业务日期点击加分或扣分与点击班级名称一致，均进入今日评价并带入该班级；历史日期只读，不进入评分详情页。 |
| 无评价权限 | 学校端最终评价权限范围 | 无权限班级不展示。 | 通过异常入口或权限实时变更导致直接进入失败时提示“暂无点评权限”；前端演示不能替代服务端鉴权。 |

##### 多班评价弹窗

| 字段 / 按钮 | 数据来源 | 展示与默认值 | 交互、校验、状态及异常 |

### 值周老师管理

#### 页面目标

仅校长在设置 tab 中管理值周老师分组。分组内的老师、负责年级和执行时间与学校端点评教师配置共同形成老师最终评价范围；非校长前端不展示设置 tab。

#### 设置 tab 与分组列表

| 字段 / 按钮 | 数据来源 | 展示与默认值 | 交互、校验、状态及异常 |
|---|---|---|---|
| 设置 tab 可见性 | 当前登录角色、学校端角色权限 | 校长展示“设置”tab；班主任、任课老师等其他角色前端不展示该 tab。 | 非校长直接访问设置页时拒绝操作并提示“暂无设置权限”；正式服务端必须校验角色权限。 |
| 顶部返回 | 固定入口 | 标题固定“班级评价”。 | 点击返回学校首页。 |
| 值周老师管理入口 | 校长设置权限 | 设置 tab 中展示值周老师管理入口；主题风格设置和值周学生管理不展示。 | 仅校长可进入。 |
| 分组名称 | 值周老师分组名称 | 分组标题展示最多 15 个字，超出使用“...”截断。 | 名称必填、不可与现有分组重名；同名保存提示“小组名称已存在，请重新输入”。 |
| 分组状态 | 当前学校日期、分组执行时间 | 状态位于分组名称右侧且不遮挡“…”：执行开始前为“待生效”（灰底黑字）；起止日期含当天为“值周中”（浅绿底绿字）；结束日期后为“已结束”（灰底红字）。 | 每次列表渲染按学校端当前日期实时计算；状态展示不替代权限服务端判断。 |
| 负责年级 | 分组负责年级配置 | 位于分组名称下方；列表最多展示 15 个字，超出“...”。 | 查看详情时完整换行展示；“全部年级”或指定年级均参与最终评价范围。 |
| 值周老师 | 分组成员、学校端教师档案 | 展开分组后展示老师头像、姓名；姓名下方展示当前职务。 | 老师姓名与职务以学校端实时教师档案为准；成员增删只影响生效期内的进行中权限，不回写历史记录。 |
| 分组折叠 | 当前页面状态 | 支持展开 / 收起。 | 点击仅影响当前分组；列表区域无感上下滑动。 |
| 更多操作 | 校长权限 | 每个分组固定右侧“…”按钮。 | 点击打开统一底部操作面板：查看分组、编辑分组、删除分组、取消；文字和按钮样式采用全局规范。 |
| 新建分组 | 校长权限 | 页面底部全宽主要按钮“新建分组”。 | 使用全局主要按钮颜色与样式；点击进入新建分组页。 |
