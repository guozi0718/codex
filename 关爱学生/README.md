## 当前确认口径

1. 三类字段同时存在时：关爱来源 → 关联信息 → 关爱类型；其他内容字段顺序保持原要求。
2. 下次跟进日期非必填；提示仅“请选择日期”。需跟进但未约定日期仍可保存；只读有日期显示日期，无日期 --。
3. 第二版当前预警自动关联且不可取消，其他预警仅历史参考；每条预警独立个案、内容和次数，不合并记录。首次提交成功才建案，之后继续关爱直接填写内容。
4. 学校与四级监管预警列表为关爱次数（N次／--）；详情来源后为关联信息，复用第一版分类弹窗。
5. 原预警／劝返字段、筛选和权限保持既定口径；监管按名称逐层下钻；老师端有效流程及第一版权限不变。
6. 未采用尚未确认的原因类型／实际措施枚举建议。
7. 学校与监管台账来源／类型列居中，超过10字省略，悬停全文。第二版关爱情况按个案存在显示唯一顶部信息卡，已建案零次也显示；未建案不显示。
8. 删除家长端原型、专属 PRD、测试清单与入口，不保留旧副本或兼容入口；不删除家长沟通等有效业务内容。既有 Git 历史不强制改写。
9. 第二版已完结“继续关爱”明确灰态、原生禁用并提示，不能通过直接入口或旧表单新增；历史详情仍可查看，第一版不改。
10. 四级监管底层预警明细按学校端统一11列的列宽、行高及对齐，仅保留详情；每校至少12条纯预警示例、10条真实分页、无感滚动及准确筛选计数。预警处理状态与关爱状态独立。
