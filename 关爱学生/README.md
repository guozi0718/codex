## 当前口径

1. 六端使用共享字典：12项关爱类型（多选）、15项关爱方式（单选），按用户给定名称与顺序，不替换原预警类型。
2. 背景顺序来源→关联→类型→原因；第二版来源锁定控辍保学，各预警独立归案，参考关联不合并。
3. 无关爱个案状态、完结禁用或下次跟进日期；有权限教师可持续关爱。继续跟进只记录本次意愿。
4. 表单不输入填写人／填写时间，保存卡末尾显示系统账号及创建时间；按实际关爱日期倒序、同日创建秒倒序。编辑不重置创建时间。
5. 本人内容可编辑／二次确认删除；无权限示例及学生范围校验保留，学校／监管关爱只读。
6. 第一版删空保留个案，只允许有权限老师确认删除空案；第二版删空自动移除当前预警关爱个案、按钮恢复关爱确认流程。
7. 学校及监管底层操作列固定右侧、业务字段内部无条滚动；原预警字段、筛选和名称下钻保留。
8. 六份PRD完整独立，不互相引用补齐；正式后端要求与HTML会话模拟区分。
