## 当前确认口径

1. 三类字段同时存在时：关爱来源 → 关联信息 → 关爱类型；其他内容字段顺序保持原要求。
2. 下次跟进日期非必填；提示仅“请选择日期”。需跟进但未约定日期仍可保存；只读有日期显示日期，无日期 --。
3. 第二版当前预警自动关联且不可取消，其他预警仅历史参考；每条预警独立个案、内容和次数，不合并记录。首次提交成功才建案，之后继续关爱直接填写内容。
4. 学校与四级监管预警列表为关爱次数（N次／--）；详情来源后为关联信息，复用第一版分类弹窗。
5. 原预警／劝返字段、筛选和权限保持既定口径；监管按名称逐层下钻；老师端有效流程及第一版权限不变。
6. 未采用尚未确认的原因类型／实际措施枚举建议。

## 代码与验证

原型包含当前七端、七个本地业务／样式资源、测试工具和老师流程／Web流程／交付链接三组回归测试；没有生产后端、真实跨端持久化或服务器上传。刷新恢复演示数据。正式实现须使用预警、学生、学校、学年、个案稳定 ID，不按姓名关联。
