> **本期已移除家长端整体范围；本文件仅作历史讨论留档，不作为本期实施或验收依据。**

> 产品版本：V1.0.0  
> 文档版本：V1.0.0_260929  
> 文档日期：2026-09-29  
> 适用范围：家长端手机小程序／关爱入口／已认领成功子女的本学年个案  
> 文档原则：独立描述新增家长端；只读，不开放新增、编辑、删除和继续跟进。

## 需求背景

家长在已完成学生认领后，需要从家长首页看到该孩子本学年的关爱个案及老师每次关爱内容。本期没有可复用的家长端关爱源文件，因此界面沿用老师端既有手机视觉结构。家长端不展示个案卡和每次关爱记录中的“关爱来源”“来源信息”两个字段；其他关爱内容按本文规则只读展示。

### 名词解释

| 术语 | 说明 |

| 关爱记录 | 老师每一次成功提交的内容；同个案在详情倒序展示全部有效记录。 |

## 功能详细说明

### 业务范围与数据口径

| 字段／规则 | 数据来源 | 计算与展示逻辑 | 联动、快照与异常 |
|---|---|---|---|
| 可见学生 | 服务端认领关系 | 仅 claimStatus=认领成功且关系有效的学生 ID；多孩分别展示。 | 取消认领、关系失效后下一次查询立即不可见，直链也拒绝。 |
| 可见个案 | 学生 ID＋本学年＋未删除状态 | 一个个案一张卡；同生可能有多个已完结个案，不合并。 | 老师删案后家长列表和详情不再显示；历史审计仍按后台要求保留。 |
| 关爱次数 | 当前案有效记录 | 1 次提交计 1，后续跟进递增，编辑不变。 | 删除单条后的次数与最近记录重新计算。 |
| 个案状态 | 最新有效记录“继续跟进” | 需要→待跟进，暂不需要→已完结。 | 若最新记录被合法删除，按上条状态回滚。 |
| 敏感字段隐藏 | 家长端渲染层和服务端家长视图 | 个案卡及每条关爱详情均不展示“关爱来源”和“来源信息”。 | 家长接口也不返回这两项的原文／原始 ID，避免仅靠 CSS 隐藏造成数据暴露。 |
| 关爱结果与证明材料 | 老师记录最新版本 | 依用户确认，家长只读可看到老师每次填写的结果与图片，不可修改。 | 图片需按现有学生认领授权鉴权；具体图片脱敏策略【待确认：现有平台家长可见图片的隐私规则】。 |

### 页面一：家长首页关爱入口

#### 页面目标

已登录家长从手机首页进入关爱页面，查看已认领成功孩子的个案；不被导航到老师端或控辍保学页。

| 字段／按钮／区域 | 数据来源 | 展示与默认值 | 交互、校验、状态及异常 |
|---|---|---|---|
| 首页“关爱” | 家长端菜单 | 原有手机端入口布局中加入“关爱”，视觉参照老师端移动端。 | 点击进入“关爱”；返回当前家长首页，无外部页面链接。 |
| 已认领孩子 | 服务端认领关系 | 展示认领成功子女；多个孩子逐个展示。 | 未认领或认领失败不显示为可见孩子。 |
| 未认领成功 | 服务端查询成功但 0 个成功关系 | 显示“暂无认领成功的孩子”；关爱入口可进入空态。 | 不允许通过猜姓名搜索其他学生。 |
| 查询失败 | 认领接口失败 | “加载失败，请重试”，不把失败当“无孩子”。 | 重试后按最新认领关系刷新。 |

### 页面二：关爱个案列表

#### 页面目标

家长查看所有成功认领孩子在本学年的个案卡，通过卡片进入详情；不能在列表上操作老师记录。

| 字段／区域 | 数据来源 | 展示与默认值 | 交互、校验、状态及异常 |
|---|---|---|---|
| 标题／返回 | 家长端路由 | 标题“关爱”；返回当前家长首页。 | 再次进入默认全部 tab【待确认：是否记忆家长上次 tab】。 |
| 全部／待跟进 | 个案最新状态 | 默认全部；待跟进只列状态为待跟进的个案。 | 按个案过滤，不按关爱记录过滤。 |
| 学生姓名搜索 | 可见孩子集合 | 占位“搜索学生姓名”；空值不筛。 | 仅在已认领可见孩子里搜索，不通过搜索扩展权限。 |
| 本学年共 N 个关爱个案 | 当前账号可见有效个案 | N≥0 整数；一个孩子多个已完结案分别计数。 | 新增、删除、状态变更后由服务端结果刷新。 |
| 卡片排序 | 当前案最近关爱日期 | 日期倒序，同日按服务端提交时间倒序。 | 点击卡片进入对应个案详情。 |
| 学生信息与状态 | 学生和最新案状态 | 姓名、年级、班级、待跟进／已完结标识。 | 不展示关爱来源或来源信息；姓名相同仍以学生 ID 区分。 |
| 创建日期 | 个案首次创建日期 | YYYY-MM-DD；单独一行，缺失“--”。 | 不由最近日期代替。 |
| 关爱次数 | 当前案有效记录数 | “N次”，N≥1。 | 增删记录后刷新。 |
| 最近关爱 | 当前案最新记录日期 | YYYY-MM-DD。 | 与详情第一张记录卡日期一致。 |
| 关爱结果 | 最新记录文本 | 最多显示 3 行，超出省略；详情全文。 | 家长端只读；空值历史记录“--”。 |
| 操作按钮 | 本期只读 | 不展示删除个案、编辑、继续跟进、新增关爱。 | 即使直链调用，也无服务端写权限。 |
| 无数据 | 查询成功、可见个案 0 | “暂无符合条件的关爱个案”，计数 0；搜索和 tab 仍可用。 | 不显示伪造示例卡。 |
| 部分数据 | 一个孩子有记录，另一个孩子无记录；或历史字段缺失 | 有案孩子正常展示；缺失字段“--”；总数按服务端全量。 | 未加载结束时显示加载态，不能提前当 0。 |
| 全量数据 | 可见孩子与个案查询完成 | 按最近关爱倒序显示全部授权个案。 | 切 tab 与搜索重新过滤完整范围。 |
| 请求失败 | 查询失败 | “加载失败，请重试”；不冒充无案。 | 重试仅恢复本账号可见范围。 |

### 页面三：关爱个案详情

#### 页面目标

家长只读查看所点个案的学生信息和老师每次关爱内容。详情不能混入该生其他个案，也不展示两个敏感来源字段。

| 字段／区域 | 数据来源 | 展示与默认值 | 交互、校验、状态及异常 |
|---|---|---|---|
| 标题／返回 | 当前可见个案 ID | 标题“关爱个案详情”；返回关爱列表。 | 进入时服务端再次校验认领关系、学年、个案有效性。 |
| 手机端容器 | 家长手机框架 | 标题固定，中间内容上下滑动，底部不放业务操作按钮；内容不得溢出手机边框。 | 关闭原图回原滚动位置。 |
| 基本信息卡 | 学生快照及个案 | 姓名、年级、班级、创建日期、关爱次数、最新状态；字段值左对齐。 | 不出现预警来源、测评来源或来源信息。 |
| 关爱情况标题 | 当前案有效记录 | “关爱情况（共N次）”；N 与列表一致。 | 同日按提交时间倒序；不混其他已完结案。 |
| 记录卡顺序 | 当前案每次关爱 | 最近到最早，第 N 次至第 1 次；卡片无字段横线。 | 每卡独立显示最新审计版本的内容，不把不同次编辑版当不同次关爱。 |
| 关爱日期 | 该次记录 | YYYY-MM-DD，缺失“--”。 | 只读。 |
| 实施人员 | 该次记录人员快照 | 完整姓名组合，自动换行，缺失“--”。 | 只读。 |
| 关爱类型 | 该次记录 | 当前字典对应显示文字，缺失“--”。 | <span style="background-color:#ffe3e3;color:#b42318">【待用户补充：类型最终枚举】</span>；家长不选择。 |
| 关爱方式 | 该次记录 | 当前字典对应显示文字，缺失“--”。 | <span style="background-color:#ffe3e3;color:#b42318">【待用户补充：方式最终枚举】</span>；家长不选择。 |
| 关爱结果 | 该次记录最新版本 | 文本跟在字段标签后，完整换行；缺失“--”。 | 无复制旧版按钮，无编辑入口。 |
| 证明材料 | 该次记录图片 | 最多 9 张，三行三列小缩略图；0 张“--”。 | 点击放大原图、可关闭；没有上传／管理按钮。 |
| 继续跟进 | 该次记录 | “需要／暂不需要”，缺失“--”。 | 只读，不出现可点的跟进按钮。 |
| 下次跟进日期 | 该次记录 | 该次“需要”时展示 YYYY-MM-DD；“暂不需要”时不展示。 | 仅显示老师记录，不生成家长任务。 |
| 关爱来源／来源信息 | 服务端家长视图 | 个案卡、基本信息、每条关爱卡全部不显示。 | 家长响应数据不包含原始来源 ID、来源文本、关联预警／心理详情。 |
| 空态／失效 | 个案被删或认领关系失效 | “个案不存在或已无查看权限”。 | 清空缓存详情，返回列表；网络失败另显示“加载失败，请重试”。 |

### 弹窗：证明材料原图

| 字段／区域 | 数据来源 | 展示与默认值 | 交互、校验、状态及异常 |
|---|---|---|---|
| 打开条件 | 当前记录缩略图 | 显示当前图片原图，背景遮罩；图片数量上限 9。 | 打开前再次校验图片属于当前授权学生个案；不通过可猜的公开 URL 泄露。 |
| 关闭 | 遮罩／关闭按钮 | 关闭原图，详情保留滚动位置。 | 不修改记录。 |
| 图片加载失败 | 图片资源请求失败 | “图片加载失败，请重试”。 | 不把破图展示为“无证明材料”。 |

## 通用权限、数据与异常规则

| 规则 | 权威来源与判定时点 | 页面表现与服务端要求 | 异常及历史数据 |
|---|---|---|---|
| 认领权限 | 现有认领系统、每次列表／详情／图片请求 | 只看当前账号认领成功孩子；关联关系失效立即拒绝后续请求。 | 历史缓存清理；不能只靠前端过滤。 |
| 本学年 | 现有学年服务 | 仅本学年案；个案跨学年如何归属【待确认：按创建日期归属还是最新关爱日期归属】。 | 原型演示日期不等于正式学年配置。 |
| 两个来源字段隐藏 | 服务端家长视图＋客户端渲染 | 卡片、详情与网络响应均不包含关爱来源、来源信息。 | 父母不得从前端调试数据、图片元信息或链接参数读到源字段。 |
| 写入权限 | 服务端鉴权 | 家长端没有新增、编辑、删除、跟进接口权限。 | 操作请求提示“暂无权限”，不产生版本或审计修改。 |
| 内容版本 | 老师端逐版审计 | 家长详情只读当前最新版本；审计旧版本不在家长端开放。 | 老师编辑后刷新可见最新结果。 |

## 验收要点

| 编号 | 操作与预期 |
|---|---|
| P-01 | 未认领成功的学生及其个案列表、详情、图片均不可见，直链也拒绝。 |
| P-02 | 两个认领成功孩子各有个案时分开展示，数量按案而不是按关爱记录计算。 |
| P-03 | 个案两次关爱时详情两张卡倒序，结果完整换行，最多九张图可看原图。 |
| P-04 | 个案卡及每次记录均不出现“关爱来源”“来源信息”；家长响应也不包含对应原文或 ID。 |
| P-05 | 页面无新增、编辑、删除、继续跟进业务按钮；老师端更新后仅刷新显示最新版本。 |
