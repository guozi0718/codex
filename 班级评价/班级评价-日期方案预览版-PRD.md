# 老师端小程序·班级评价产品需求文档 V1.0

> 项目性质：新建项目｜产品版本：V1.0（第一版）｜文档日期：2026-09-11  
> 产品范围：学校侧老师端小程序「班级评价」模块  
> 本文仅描述最终版原型需要实现的页面、字段、交互、数据来源和业务规则。

## 1. 产品概述

### 1.1 产品目标

为校长、班主任、任课老师等学校角色提供班级评价入口，完成班级排行查看、今日评价、评价记录查询和值周老师配置，并保证评价结果、计分规则、权限范围和历史快照可追溯。

### 1.2 产品范围

| 模块 | 功能目标 | 主要页面 |
|---|---|---|
| 排行 | 按时间、年级、指标维度查看班级总分排名 | 排行 tab |
| 评价 | 查看指定日期且当前老师有权限操作的班级加分、扣分，并进入今日评价 | 评价 tab、今日评价页 |
| 记录 | 按评价来源、指标维度和评价类型查看评价快照 | 记录 tab |
| 设置 | 管理值周老师分组、老师、负责年级和执行时间 | 设置 tab、值周老师管理页 |

### 1.3 数据来源

| 数据对象 | 来源 | 使用范围 |
|---|---|---|
| 一级指标维度、二级指标维度、检查项 | 学校端 Web 的检查指标库 | 今日评价、评价记录、排行筛选和统计；展示顺序以学校端配置顺序为准 |
| 检查项默认分值、启用状态 | 学校端 Web 的检查项设置 | 今日评价的单次加分/扣分规则；实时变更，历史记录不受影响 |
| 初始总分 | 学校端系统统一配置 | 排行全部维度默认使用100分作为初始分 |
| 年级、班级、班级创建时间 | 学校端班级数据 | 年级筛选、班级列表、同分排序和权限范围 |
| 年级+班级展示名称 | 学校端当前学年的年级类型名称、班级编号对应的班级名称 | 前端统一展示为“年级名称-班级名称”，例如“一年级-1班”；后端取当前学年、年级类型和班级编号 |
| 学生、学生在读状态、学生实时班级归属 | 学校端学生数据 | 关联学生、扫码识别和提交校验 |
| 学校校历、学年和学期 | 学校端校历 | 时间范围、周期切换和统计边界 |
| 排班表 | 学校端排班数据 | 可评价时间范围；评价时间范围为排班表与当前学年的交集 |
| 点评教师配置、值周老师分组及负责年级 | 学校端配置及老师端值周老师设置 | 评价权限；配置实时生效，历史记录不受影响，进行中的评价受影响 |
| 老师当前职务 | 学校端教师档案 | 值周老师列表、分组展开和选择值周老师页面；老师姓名下方展示当前职务 |

## 2. 全局交互与视觉规范

### 2.1 导航与页面默认状态

| 字段/入口 | 规则 |
|---|---|
| 首页班级评级入口 | 点击进入班级评价模块，默认打开排行 tab 的默认页 |
| 底部常驻 tab | 固定为“排行、评价、记录、设置”；每次点击 tab 均打开该 tab 的默认页，不保留上次操作页 |
| 顶部返回标题 | 排行、评价、记录、设置及其子页面顶部返回标题统一显示“班级评价” |
| 顶部返回行为 | 返回首页，不返回上一次 tab 或上一次子页面 |
| 今日评价页顶部返回 | 返回进入今日评价页之前的来源页面；从记录进入则回记录页，从评价班级/扫码/多班评价进入则回评价页 |
| 设置权限 | 仅校长角色可看到并操作设置 tab；权限变更实时生效 |

### 2.2 容器与按钮

| 字段/区域 | 规则 |
|---|---|
| 上下滑动容器 | 数据列表、检查项列表、记录列表、值周老师选择列表等内容区域支持上下滑动；滑动条不明显，不展示明显滑块 |
| 左右滑动容器 | 指标维度卡片、检查项二级维度卡片等横向内容支持左右滑动；滑动条不明显 |
| 一级维度折叠/展开 | 所有页面统一使用模块颜色的折叠/展开样式；选中态使用模块颜色，不使用对勾 |
| 取消按钮 | 统一使用白底、模块色边框和模块色文字的次要按钮样式 |
| 确定/提交按钮 | 统一使用模块主色实心按钮和白色文字；评价提交按钮名称为“完成评价” |
| 更多操作按钮 | 删除、编辑等操作菜单统一使用“更多操作”样式；菜单文字颜色和按钮样式全局统一 |
| 删除弹窗标题 | 标题统一为“删除”，靠左对齐 |
| 空值 | 关联学生、评价内容等字段无内容时统一展示“--”；“--”与字段名同一行展示 |
| 文本截断 | 评价内容最多展示三行，超出部分省略；有内容从字段名同一行开始展示 |

### 2.3 业务状态

| 状态 | 规则 |
|---|---|
| 在评内容 | 仅保存在当前页面内；今日评价页面离开或刷新时直接清空，不弹出离开提示 |
| 正式记录 | 仅点击“完成评价”并提交成功后生成；一个检查项对应一条评价记录 |
| 失败提交 | 全部成功时进入评价页并清理本次在评内容；全部失败时提示“本次评价提交失败，请重新进入页面编写” |
| 部分提交 | 本版本按全部成功或全部失败处理，不生成部分成功结果 |

## 3. 时间与统计规则

### 3.1 时间维度

| 字段/页面 | 可选值 | 默认值 | 交互规则 |
|---|---|---|---|
| 排行时间维度 | 本周、本月、本学期、本学年 | 本周 | 切换后重新计算并展示排名 |
| 评价 tab 日期 | 今日或“YYYY-MM-DD” | 今日 | 通过日期筛选选择当前学年内历史日期；未来日期置灰不可选 |
| 记录时间维度 | 本周、本月、本学期、本学年 | 本周 | 时间切换后同步刷新统计与记录 |
| 设置执行时间 | 起止日期范围 | 当日 至 本学期最后一天 | 新建/编辑时两端均必填；展示格式为“YYYY-MM-DD 至 YYYY-MM-DD”，内容靠右对齐 |

### 3.2 日期边界

| 字段/规则 | 逻辑 |
|---|---|
| 学年查看范围 | 老师端可查看的数据仅限当前学年；不支持查看往学年 |
| 可评价时间范围 | 由学校端排班表与当前学年取交集；不出现跨周的历史评级 |
| 未来日期 | 所有未来时间一律置灰且不可选中 |
| 历史评价新增 | 不支持对今日以外的历史日期新增评价；扫码评价、多班评价和班级详情评价均进入今日评价 |
| 跨日提交 | 打开页面后若评价日期已跨日，提交不可成功，提示“当前评价日期已变更，无法提交今日评价。” |
| 周/月/学期/学年统计 | 进行中的周期依据最新初始分计算；已经形成的评价按评价形成时的配置项分值计算；配置修改后的新评价按新配置计算；已结束周期按当时初始分和配置项分值计算 |

### 3.3 日期显示与选择

| 字段/区域 | 规则 |
|---|---|
| 日期控件 | 需要日期选择的页面沿用统一日期控件；未来日期置灰；仅允许选择当前学年范围内的日期 |

## 4. 计分与记录规则

### 4.1 分值定义

| 字段 | 逻辑 |
|---|---|
| 总分 | 全部维度下，同一时间维度内总分 = 100 + 各一级指标净得分；总分允许为负数或超过 100.0 分 |
| 一级指标净得分 | 选定单个一级指标维度时，同一时间维度内净得分 = 总加分 - 总扣分，总扣分取绝对值；净得分允许为负数 |
| 初始总分 | 学校端系统统一配置；排行全部维度默认初始分为100分 |
| 检查项默认分值 | 来源于学校端 Web 的检查项设置；允许一位小数；作为分值倍数计算的基准值；单项最低值和最高值同样以检查项管理配置为准 |
| 单项结果范围 | 单个检查项分值的最低值和最高值取学校端 Web【班级评价】-【检查项管理】配置；前端按一位小数的正数格式展示和校验，超过配置上限时提示“单个检查项不允许超过100.0分” |
| 学校端异常分值 | 学校端为 0 分时按 0 分处理；缺失分值按 0.0 分处理；超过 100.0 分按 100.0 分处理 |
| 历史记录分值 | 历史记录保存提交时的检查项分值和相关配置快照；之后学校端配置变更不修改历史记录分值 |

### 4.2 关联学生计分

| 场景 | 逻辑 |
|---|---|
| 未关联学生 | 用户可直接使用默认分值评价班级；填写或不填写图文均按检查项默认分值计入 |
| 关联学生 | 可选择并保存关联学生；分值不按关联学生数量变化，统一按检查项默认分值的倍数计算，点击数字可修改；不论填写或不填写图文均按当前分值计入 |
| 多班未关联学生 | 选择多个班级、未选择关联学生时，所选班级均扣/加相同分值 |
| 多班关联学生 | 选择多个班级并关联学生时，所有选中班级均按同一检查项分值加/扣分；每个班级的单个检查项结果分别按学校端配置范围校验 |
| 取消全部学生 | 仅取消关联学生，不改变此前手动输入的分值；若此前未手动输入，则保持检查项默认分值 |

### 4.3 记录修改与删除

| 字段/动作 | 规则 |
|---|---|
| 可修改字段 | 评价记录仅允许修改图文评价内容；不允许修改原评分和关联学生 |
| 修改时限 | 本人提交的评价记录可修改图文内容，时间不限；允许学生已离校、转班或毕业时修改图文内容 |
| 可删除范围 | 仅允许删除本人提交的评价记录；非本人记录只读，无编辑、删除入口 |
| 删除方式 | 点击更多操作，底部弹窗依次展示“修改、删除、取消”；点击删除后弹出二次确认，标题为“删除”，正文为“确定删除该检查项内容？”；按钮为“取消”“确定” |
| 删除存储 | 前端立即隐藏；后端保留原评价快照、删除人和删除日期 |
| 评价日期 | 修改或删除不改变原评价日期 |

## 5. 排行 tab

### 5.1 页面结构

| 区域/字段 | 逻辑 |
|---|---|
| 页面标题 | 班级评价 |
| 顶部视觉区 | 展示排行榜视觉区域和总分说明入口 |
| 时间筛选 | 可选本周、本月、本学期、本学年；默认本周；切换后立即重新计算并展示排名 |
| 年级筛选 | 默认全部年级；取当前学年所有年级及“全部”，全部置于最前；支持单选、多选；一行三个等宽卡片；选择“全部”后立即生效 |
| 指标维度筛选 | 默认全部维度；取学校端指标库的全部一级指标维度；横向容器滑动；选择后刷新排名 |
| 数据列表 | 展示全部班级，按总分从高到低排序；容器上下滑动；不展示明显滑块 |

### 5.2 排名字段

| 字段 | 逻辑 |
|---|---|
| 名次 | 前三名使用现有奖牌 icon；第4名及以后使用底色圆形加内部数字；同分默认并列，名次跳号，例如 1、2、2、4 |
| 同分顺序 | 同分班级按班级创建时间排序；创建时间相同按学校端返回顺序 |
| 班级名称 | 展示为“年级名称-班级名称”，例如“一年级-1班”；后端取当前学年、年级类型名称和班级编号对应的班级名称 |
| 总分/净得分 | 全部维度时字段为“总分”，计算为100+各一级指标净得分；选择单个一级指标时字段为“净得分”，计算为总加分-总扣分（总扣分取绝对值）；均允许负数或超过100分 |
| 总分说明按钮 | 点击打开“总分统计说明”弹窗；弹窗关闭按钮为“关闭” |

### 5.3 总分统计说明

| 字段/文案 | 内容 |
|---|---|
| 标题 | 总分统计说明 |
| 说明1 | 评分方式：按时间维度进行总分排名； |
| 说明2 | 总分计算：同一时间维度下，总分=初始分+各一级指标的净得分； |
| 说明3 | 默认初始分：100分。 |
| 关闭按钮 | 关闭弹窗；使用统一主色按钮样式 |

### 5.4 一级指标维度排行说明

| 字段/文案 | 内容 |
|---|---|
| 表头字段 | 选择单个一级指标维度时，“总分”改为“净得分” |
| 标题 | 净得分统计说明 |
| 说明1 | 评分方式：按时间维度进行净得分排名； |
| 说明2 | 净得分计算：同一时间维度下，净得分=总加分-总扣分，总扣分取绝对值。 |

## 6. 评价 tab

### 6.1 页面结构与日期

| 区域/字段 | 逻辑 |
|---|---|
| 页面标题 | 班级评价 |
| 顶部时间区域 | 页面顶部直接进入年级、指标维度和日期筛选区域，不设置独立时间视觉区域 |
| 年级筛选 | 全部年级及当前学年年级；一行三个等宽卡片；选择后立即生效 |
| 指标维度筛选 | 全部维度及一级指标维度；一行三个等宽卡片；选择后立即生效 |
| 日期筛选 | 与年级、指标维度三个筛选项均匀分布；默认今日；底部日历弹窗支持选择本学年内历史日期，未来日期置灰不可选；今日显示“今日”，历史日期按“YYYY-MM-DD”显示 |
| 多班评价入口 | 与扫码入口同一行，各占一半；展示统一多班评价 icon；文字为“多班评价” |
| 数据区域 | 展示当前日期、年级和指标维度下的班级评价数据；容器上下滑动；班级按年级分组，默认展开 |

### 6.2 年级与班级数据

| 字段/操作 | 逻辑 |
|---|---|
| 年级标题 | 展示年级名称和班级数量；点击标题或折叠/展开按钮切换班级显示状态 |
| 班级布局 | 每行两个班级卡片，自动向下补位，不支持左右滑动 |
| 班级名称/加分/扣分 | 当前老师可操作评价的班级才展示；数据位于对应年级分组下，班级位置仅展示班级名称（如“1班”）；班级名称、加分和扣分均点击进入今日评价页 |
| 权限班级 | 无评价权限的班级及其年级不展示；权限以学校端配置实时生效 |

### 6.3 评价入口

| 入口 | 逻辑 |
|---|---|
| 扫校徽码评价 | 扫码进入今日评价页，识别校徽学生当前实时归属的班级并默认选中该学生；仅可评价该班级 |
| 多班评价 | 点击打开底部多班评价弹窗；按年级折叠/展开，默认展开；班级卡片一行三个等宽布局；选中数量实时展示 |
| 多班确认 | 点击“确定”进入今日评价页，带入所选班级；仅可评价这些班级；未选班级不可进入评价 |
| 取消 | 关闭多班评价弹窗，不改变已提交记录 |

### 6.4 多班评价弹窗

| 字段/区域 | 逻辑 |
|---|---|
| 标题 | 多班评价 |
| 年级选择 | 展示年级名称、已选班级数/该年级实时班级总数；已选数量使用模块色，分母使用黑色 |
| 班级折叠 | 每个年级默认展开；点击折叠/展开按钮切换；按钮使用统一模块色折叠/展开样式 |
| 班级卡片 | 一行三个等宽卡片；选中使用模块色背景/边框，不使用对勾 |
| 容器 | 弹窗内容区域支持上下滑动，不展示明显滑块 |

## 7. 今日评价页

### 7.1 进入与数据

| 字段/规则 | 逻辑 |
|---|---|
| 进入路径 | 来自评价 tab 的扫码、多班评价、班级名称；记录页仅用于查看和管理评价记录 |
| 评价对象 | 扫码带入识别班级；多班评价带入所选班级；点击评价 tab 的班级、加分或扣分均带入对应班级 |
| 指标库 | 一级指标、二级指标、检查项均实时取学校端 Web 检查指标库；展示顺序完全按学校端配置顺序 |
| 检查项变更 | 检查项未提交时如学校端修改该项，提交/确定时提示“检查项已变更，请重新进入当前页面” |
| 检查项停用 | 确定时校验检查项启用状态；停用时提示“学生状态错误，请重新进入”仅适用于学生状态，检查项状态按同一校验链路阻止保存并提示重新进入 |
| 页面结构 | 今日评价为非主页面；不保留底部四项 tab，底部空间补齐 |
| 页面刷新/离开 | 未提交的在评内容不保存，暂无提示弹窗；顶部返回按进入来源返回 |

### 7.2 筛选与维度导航

| 评价记录 ID | 服务端生成 | 不直接展示 | 不变 |
| 评价日期时间 | 服务端提交时间 | 展示原评价日期时间 | 不变 |
| 评价老师 | 当前登录老师 | 展示老师姓名；筛选时不带身份 | 不变 |
| 班级 ID/名称 | 提交时班级信息 | 展示“年级名称-班级名称”格式的当时班级 | 不变 |
| 学生 ID/姓名/班级 | 提交时关联学生快照 | 展示“年级名称-班级名称”和姓名；无内容为“--” | 不允许修改 |
| 一级指标维度 | 提交时配置快照 | 展示维度名称 | 不允许修改 |
| 二级指标维度 | 提交时配置快照 | 展示维度名称 | 不允许修改 |
| 检查项 | 提交时检查项快照 | 展示检查项名称 | 不允许修改 |

| 实际分值 | 按提交时配置和用户确认分值保存 | 展示实际值 | 不允许修改 |
| 评价内容 | 用户填写的文字和附件 | 最多三行；无内容为“--” | 本人可修改，时限不限 |
| 删除状态 | 默认有效 | 有效记录展示 | 删除后前端隐藏，后端保留 |
| 删除人/删除日期 | 删除操作产生 | 前端不展示 | 后端保留用于审计 |

## 18. 统计计算示例

| 场景 | 计算逻辑 | 展示结果 |
|---|---|---|
| 单维度今日净得分 | 今日总加分 - 今日总扣分，总扣分取绝对值 | 选择一级指标维度时作为排行净得分，允许为负数 |
| 全部维度本周总分 | 100 + 各一级指标本周净得分 | 作为排行总分，允许超过100分或为负数 |
| 未关联学生扣分 | 检查项默认分值及用户确认的倍数 | 每个目标班级按相同分值扣分 |
| 关联学生扣分 | 关联学生不参与分值计算 | 每个目标班级仍按相同分值扣分；学生仅作为记录快照 |
| 多班评价 | 选中班级均按同一检查项分值计入；关联学生仅按实际班级保存学生快照 | 每班生成实际记录和班级结果 |
| 进行中周期 | 使用最新初始分计算周期当前汇总 | 已形成记录仍使用提交时快照 |
| 已结束周期 | 使用周期内记录当时的初始分和配置项分值 | 配置修改不重算历史记录 |
| 学校端缺失分值 | 缺失值按0.0分 | 不阻止统计 |
| 学校端超过上限 | 单项按100.0分处理 | 统计结果按处理后值计算 |

## 20. 服务端数据与一致性要求

| 业务对象 | 服务端要求 |
|---|---|
| 指标库 | 返回一级维度、二级维度、检查项的 ID、名称、层级关系、配置顺序、启用状态和当前默认分值 |
| 配置版本 | 检查项打开、确定和完成评价时均可校验配置版本；版本变化时阻止保存并返回“检查项已变更，请重新进入当前页面” |
| 班级 | 返回当前学年班级 ID、年级类型、年级名称、班级编号、班级名称、创建时间及状态；前端统一展示“年级名称-班级名称”，排行同分排序使用创建时间 |
| 学生 | 返回学生 ID、姓名、在读状态和实时班级归属；提交时重新校验，不以前端缓存为准 |
| 评价权限 | 服务端根据学校端点评教师配置、值周老师分组、负责年级和执行时间校验；当前老师无操作权限的班级不展示；前端隐藏入口不替代服务端鉴权 |
| 排班表 | 返回可评价日期范围；与当前学年交集后用于评价日期校验 |
| 评价记录 | 每个检查项独立落库；记录保存分值、方向、班级、学生、指标、检查项和配置快照 |
| 修改记录 | 仅允许修改本人记录的图文内容；评分、学生、原评价时间和业务快照不可修改 |
| 删除记录 | 逻辑删除；保留原记录快照、删除人、删除日期和操作审计信息 |
| 批量提交 | 多班评价一次提交可包含多个班级和多个检查项；服务端按检查项、班级拆分处理；关联学生仅保存学生快照，不改变各班分值；全部成功或全部失败 |
| 跨日校验 | 以服务端时间为准；页面打开日期与提交日期不一致时拒绝提交 |
| 懒加载 | 记录列表支持游标或等价分页方式；前端滚动到底部自动请求下一批，避免一次加载全部记录 |
