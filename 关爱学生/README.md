## 第三版口径

每次新建一条关爱记录，重新选年级/班级/学生，按来源→类型→原因→时间→执行人→方式→结果→材料填写。每条只有一次内容，不追加、不合并，不设置个案状态、关联信息和继续跟进。类型12项多选、方式15项单选，来源多选；结果最多100字，日期可补录但不得未来。

老师只有在有功能权限、学生在授权范围且为本人记录时才能编辑/删除。系统创建账号和时间不可手填；修改保留原创建时间，前后快照审计。学校/监管只读，底层列表不放关联信息和次数；监管上级按名称下钻，汇总学生去重人数和独立记录次数，不按执行人数计次。

第一版仍为个案内多次内容，第二版仍为每个预警独立关爱；它们的继续关爱、删空分支不被第三版覆盖。
